# Freegate VPN Storefront

This is the repository for my final project for the B204 App & Web Development module. It's a simple e-commerce storefront designed for selling VPN and Proxy services.

## Tech Stack
* **Frontend:** Plain HTML, CSS, and Vanilla JavaScript
* **Backend:** Node.js with Express.js
* **Database:** MongoDB
* **Infrastructure:** Docker

## How to Run

Make sure you have Docker Desktop installed and running on your machine.

1. Open your terminal in this directory.
2. Run the following command to build and start the containers:
   ```bash
   docker-compose up --build -d
   ```
3. Once the containers are up and the database connects, the application will be available at `http://localhost:5000`.
